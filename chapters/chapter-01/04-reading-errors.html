Reading error messages

☕ Campus Bites

Luis typed pritn("Hello") and got a scary red message. He thinks he broke the computer. He did not.

Why?

Everyone makes mistakes, even experts. An error message tells you what went wrong and where.

How it works

An error message names the problem and the line number. Read the last line first. It says the kind of error and what Python saw.

Try it Yourself


💥 Break it on purpose
Luis made a typo in print. Press Run and read the last line.
What happened?
This is a NameError. Python does not know the name pritn. Fix the spelling: print.


💥 Break it on purpose
Luis forgot the closing bracket. Press Run.
What happened?
This is a SyntaxError. Python reached the end and the bracket was still open. Add ).
