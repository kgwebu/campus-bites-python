Assignment 2. Menu Toolkit

Skills: dictionaries, functions, parameters, default values, keyword arguments, *args, return, lambda with sorted and min, raise, assert, modules. Time: about 2.5 hours.

The story

Luis is tired of copying the same price code again and again. Amina says, "Build a toolkit we can reuse. Other people will call your functions with menus you have never seen." So your functions must work for any menu and any order, not only for ours.

Your numbers

🔢 Your numbers

Every student gets different numbers, worked out from the GitHub username. Type yours to see them. Your program and your self-check use these.

Type your GitHub username in the card. It shows your menu, your discount numbers, and your two rules. A classmate's code will not pass with your numbers. The marking program uses your numbers too.

What you must build

Two files, in a folder called assignment-2. Create them from scratch. There is no starter code.

  • menu_tools.py holds your menu and eight functions.
  • menu_main.py imports the module, checks it with assert, and prints a report.

Your menu

In menu_tools.py, write a dictionary called MENU. The keys are item names. The values are prices (floats). Use exactly your five items:

Item Price

An order is a dictionary of item name to whole-number quantity, like {"Espresso": 3, "Bagel": 2}. A menu passed to a function is a dictionary of item name to price. Your functions must use the menu they are given, never your own MENU inside the function.

The eight functions

Function What it does
price_of(item, menu) The price, or None if the item is not on the menu
require_price(item, menu) The price. If the item is not on the menu: raise ValueError(f"Unknown item: {item}")
order_total(order, menu) Sum of price times quantity, rounded to 2 decimals. Empty order gives 0. Unknown item: same ValueError as above. A quantity that is not a whole number of 1 or more: ValueError(f"Bad quantity for {item}: {qty}")
discount_percent(order, member=False, *, bulk_at=..., bulk_pct=..., member_pct=...) The discount percent for the order. See the rules below. The three keyword-only values have your numbers as defaults
apply_discount(total, pct=0, rounding=...) Takes pct percent off total, then rounds by rounding. pct defaults to 0. rounding defaults to your rounding rule. A pct below 0 or above 100: ValueError(f"Bad percent: {pct}"). An unknown rounding word: ValueError(f"Unknown rounding: {rounding}")
rank_items(menu, descending=False, limit=None) A new list of item names sorted by price. Ties go A to Z, in both directions. If limit is given, only the first limit names
merge_orders(a, b) A new dictionary with the quantities of a and b added. It must not change a or b
cheapest_of(menu, *names) The cheapest of the names you pass (any number of them). Ties go A to Z. No names: ValueError("Give at least one item"). A name not on the menu: the Unknown item error

Your discount rule

Count the units in an order: the sum of all its quantities.

  • Bulk part: if units are at least bulk_at, the bulk part is bulk_pct. Otherwise it is 0.
  • Member part: if member is true, the member part is member_pct. Otherwise it is 0.
  • Your numbers: bulk_at is , bulk_pct is , member_pct is .
  • Your rule: . add means the two parts are added. larger means you use only the larger of the two parts.

Your rounding rule

apply_discount works out total * (100 - pct) / 100, then rounds by the rounding word:

Word Meaning Example: 12.346
"nearest" to the nearest cent 12.35
"down" down to a whole cent 12.34
"up5" up to the next multiple of 0.05 12.35

Your default word is . The function must still handle all three words when asked.

Functions return their answer. They never print and never input. Printing belongs in menu_main.py. Hint for "down" and "up5": put import math at the top and look up math.floor and math.ceil.

The __main__ guard

At the bottom of menu_tools.py, add a block that starts if __name__ == "__main__":. Put two or three assert lines in it. Nothing may print when another file imports menu_tools. Every function needs a docstring.

The report

menu_main.py imports from menu_tools and has at least 3 assert lines. It builds two orders from your own item names:

  • Order A: 3 × , 2 × . Not a member.
  • Order B: 5 × , 3 × , 4 × . A member.

It prints exactly these 13 lines. Money has 2 decimals. Percents use {pct:g} so 10 prints as 10.

Menu Toolkit report
Cheapest item: <name from cheapest_of over all MENU items>
Priciest item: <first name of rank_items(MENU, descending=True)>
Price of Pizza: <what price_of returns for Pizza>
Order A total: <order_total of A>
Order A discount: <discount_percent of A>%
Order A pays: <apply_discount of A total and its percent, default rounding>
Order B total: <order_total of B>
Order B discount: <discount_percent of B, member>%
Order B pays: <apply_discount of B total and its percent, default rounding>
Both orders together: <order_total of merge_orders(A, B), no discount>
Ranking: <all names, priciest first, joined with ", ">
Error check: <the message of the ValueError from require_price("Pizza", MENU)>

The last line must come from a real try / except ValueError as err. The marking program runs your menu_main.py with other menu prices. If you typed the numbers into print, it fails.

"""Self-check for Assignment 2. Put this file, variants.py, menu_tools.py and menu_main.py in one folder, then run it.

It checks YOUR numbers (they come from your GitHub username). The real marking uses more checks and other menus.
"""
import ast
import importlib
import subprocess
import sys

USERNAME = ""  # optional: type your GitHub username here to skip the question

try:
    from variants import pick
except ImportError:
    sys.exit("Could not find variants.py. Download it and save it in this folder.")

name = USERNAME or input("GitHub username: ")
v = pick("a2", name)
my_menu = {v["drink_1"]: float(v["drink_1_price"]), v["drink_2"]: float(v["drink_2_price"]),
           v["bake_1"]: float(v["bake_1_price"]), v["bake_2"]: float(v["bake_2_price"]),
           v["meal"]: float(v["meal_price"])}
NAMES = ["price_of", "require_price", "order_total", "discount_percent", "apply_discount",
         "rank_items", "merge_orders", "cheapest_of"]
results = []


def check(label, test):
    try:
        ok = bool(test())
    except Exception as e:  # a crash is a fail, with a hint
        ok = False
        label += f"   (error: {type(e).__name__}: {e})"
    results.append(ok)
    print(("PASS  " if ok else "FAIL  ") + label)


def raises(message, fn, *args, **kwargs):
    try:
        fn(*args, **kwargs)
    except ValueError as e:
        return str(e) == message
    return False


try:
    m = importlib.import_module("menu_tools")
except Exception as e:
    sys.exit(f"Could not load menu_tools.py: {type(e).__name__}: {e}")

tiny = {"Tea": 2.0, "Roll": 1.5, "Cake": 2.0}
check("MENU has your 5 items and your prices", lambda: {k: float(x) for k, x in m.MENU.items()} == my_menu)
check("all 8 functions exist and each has a docstring",
      lambda: all(callable(getattr(m, n, None)) and (getattr(m, n).__doc__ or "").strip() for n in NAMES))
check("price_of gives None, and require_price raises ValueError('Unknown item: Pizza')",
      lambda: m.price_of("Pizza", tiny) is None and m.price_of("Tea", tiny) == 2.0
      and raises("Unknown item: Pizza", m.require_price, "Pizza", tiny))
check("order_total adds price x quantity", lambda: m.order_total({"Tea": 2, "Roll": 3}, tiny) == 8.5)
check("discount_percent uses bulk_at, bulk_pct and member_pct",
      lambda: m.discount_percent({"Tea": 3}, bulk_at=3, bulk_pct=10, member_pct=2) == 10
      and m.discount_percent({"Tea": 2}, bulk_at=3, bulk_pct=10, member_pct=2) == 0
      and m.discount_percent({"Tea": 2}, True, bulk_at=3, bulk_pct=10, member_pct=2) == 2)
check("discount_percent defaults are the numbers on your card",
      lambda: m.discount_percent({"Tea": int(v["bulk_at"])}, True)
      == m.discount_percent({"Tea": int(v["bulk_at"])}, True, bulk_at=int(v["bulk_at"]), bulk_pct=int(v["bulk_pct"]),
                            member_pct=int(v["member_pct"])))
check("apply_discount: (80, 25, 'nearest') is 60.0, pct defaults to 0, rounding defaults to your rule",
      lambda: m.apply_discount(80, 25, "nearest") == 60.0 and m.apply_discount(80) == 80
      and m.apply_discount(19.99, 15) == m.apply_discount(19.99, 15, v["rounding_rule"]))
check("rank_items: ties are A to Z, also when descending",
      lambda: m.rank_items(tiny) == ["Roll", "Cake", "Tea"] and m.rank_items(tiny, descending=True) == ["Cake", "Tea", "Roll"]
      and m.rank_items(tiny, limit=1) == ["Roll"])
a, b = {"Tea": 1}, {"Tea": 2, "Roll": 1}
check("merge_orders adds quantities and does not change its inputs",
      lambda: m.merge_orders(a, b) == {"Tea": 3, "Roll": 1} and a == {"Tea": 1} and b == {"Tea": 2, "Roll": 1})
check("cheapest_of takes any number of names (ties A to Z)",
      lambda: m.cheapest_of(tiny, "Tea", "Cake") == "Cake" and m.cheapest_of(tiny, "Tea") == "Tea"
      and raises("Give at least one item", m.cheapest_of, tiny))


def main_checks():
    try:
        src = open("menu_main.py", encoding="utf-8").read()
        tree = ast.parse(src)
    except (OSError, SyntaxError) as e:
        check(f"menu_main.py can be read ({type(e).__name__})", lambda: False)
        return
    check("menu_main.py imports menu_tools and has 3 or more assert lines",
          lambda: "menu_tools" in src and sum(isinstance(n, ast.Assert) for n in ast.walk(tree)) >= 3)
    try:
        run = subprocess.run([sys.executable, "menu_main.py"], capture_output=True, text=True, timeout=20)
    except subprocess.TimeoutExpired:
        check("menu_main.py finishes", lambda: False)
        return
    lines = run.stdout.splitlines()
    check("menu_main.py runs and prints the 13 report lines (first 'Menu Toolkit report', last 'Error check: ...')",
          lambda: run.returncode == 0 and len(lines) == 13 and lines[0] == "Menu Toolkit report"
          and lines[3] == "Price of Pizza: None" and lines[-1] == "Error check: Unknown item: Pizza")


main_checks()
print(f"\n{sum(results)} of {len(results)} checks passed.")

Add NOTES.md (see the integrity note below). Commit and push to your GitHub repo.

If it did not work
  • ModuleNotFoundError: No module named 'menu_tools': the files must be in the same folder, and you must open that folder in VS Code.
  • ModuleNotFoundError: No module named 'variants': download variants.py into the same folder as the self-check.
  • A function prints None: you forgot return, or you used print inside the function.
  • My merge_orders changes the first order: merged = a does not copy. Use dict(a) or a.copy().
  • Descending ties are in the wrong order: reverse=True also reverses the names. Use a key such as (-price, name).
  • TypeError: ... got an unexpected keyword argument: the parameter name must match the table exactly.
  • A number like 3.4499999999999997: use round(value, 2) in order_total.
  • The self-check says it cannot find your numbers: check the spelling of the username. Capital letters do not matter.
