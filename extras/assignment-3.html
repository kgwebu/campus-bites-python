Assignment 3. Messy Orders

Skills: reading CSV files, try / except, classes, pandas groupby, a matplotlib chart. Time: about 3 hours.

The story

Luis typed a month of orders into orders.csv. Some rows are wrong: a quantity of two, a blank quantity, -1 coffees, even a product called Cookie that Campus Bites does not sell. Amina wants a clean file, a short report, and a chart.

Amina has her own rules about what counts. Your rules are personal. Type your GitHub username below to see them.

🔢 Your numbers

Every student gets different numbers, worked out from the GitHub username. Type yours to see them. Your program and your self-check use these.

Your rules

Every rule below uses a number or word from your card. Your classmates have different ones.

Rule Your value
Maximum quantity per order (a bigger quantity is bad)
Name rule
What to do with Cookie
Best day is the day with the most
Top products cut-off (dollars of revenue) $
First day that counts
Last day that counts
  • Name rule exact: use the product text exactly as typed. coffee and Coffee do not match Coffee.
  • Name rule tidy: first remove spaces from both ends, then make it title case (.strip().title()). So iced TEA becomes Iced Tea.
  • Cookie bad: a Cookie row is a normal unknown product.
  • Cookie is a product name (for example Muffin): after the name rule, change the name Cookie to that product, then continue as usual. Count each such row in the Aliased rows line.
  • Best day: revenue means the most revenue. profit means the most profit.

Money words

  • revenue = price times quantity, rounded to 2 decimals.
  • profit = (price minus cost) times quantity, rounded to 2 decimals.
  • menu.csv has three columns: product,price,cost.

What your program must do

Your file is called messy_orders.py. It must read orders.csv and menu.csv from the current folder every time it runs. Do not type prices or product names into your code. Marking runs your program on a different, smaller orders.csv and menu.csv with tricky rows, so a program with copied numbers fails.

Class Order. Put it in messy_orders.py with a docstring. It needs:

  • __init__(self, order_id, date, product, quantity, price, cost) that stores all six as attributes with the same names.
  • revenue() and profit() that return numbers rounded to 2 decimals.
  • __str__ that returns exactly O0004 | 2026-03-01 | Muffin x2 | revenue $6.50 | profit $4.30 (your own values, same shape).
  • __eq__ that says two orders are equal when their order_id is the same. Comparing with anything that is not an Order gives False and no error.

The class must work on its own: it must not use any other name from your file.

Read the files. Read menu.csv into a dictionary. Read orders.csv with csv.DictReader. If either file is missing, print Missing file: menu.csv (or Missing file: orders.csv) and stop. No traceback. Check menu.csv first.

Judge every row, in exactly this order. The first test a row meets decides what happens to it. Trim spaces from the order_id, the date and the quantity text before you use them.

  1. bad date: the date is not written exactly YYYY-MM-DD or is not a real day (2026-02-30, March 5, an empty date).
  2. outside the window: the date is before your first day or after your last day. Your first and last days count. These rows are skipped. They are not bad rows.
  3. unknown product: apply your name rule, then your Cookie rule, then look the name up in the menu. Not found means bad.
  4. quantity not a number: int() raises ValueError (for two, an empty cell, 2.5). Use try / except.
  5. quantity 0 or less.
  6. quantity over your maximum. A quantity equal to your maximum is fine.
  7. duplicate order id: an order with this order_id is already accepted. The first accepted row stays. Use your __eq__ to test this. A row that was bad does not block a later row with the same id.

A row that passes all seven is a good row.

What your program prints

Print these lines, in this order. Words, spaces and punctuation must match. Replace the angle brackets with your numbers. Spaces at the start of a line do not matter.

Window: <first day> to <last day>
Rows read: <number of rows DictReader gave you>
Outside window: <number>
Good rows: <number>
Bad rows: <number>

  unknown product: <number>
  quantity not a number: <number>
  quantity 0 or less: <number>
  quantity over <your maximum>: <number>
  duplicate order id: <number>

1. <product>: $<revenue>
2. <product>: $<revenue>
Best day by <revenue or profit>: <date> ($<total>)
Weekday summary:
Monday: <n> orders, revenue $<revenue>, profit $<profit>
Tuesday: <n> orders, revenue $<revenue>, profit $<profit>
First 3 orders:
<str of order 1>
<str of order 2>
<str of order 3>
  • Print all six reasons even when a count is 0. Use your own maximum in the quantity over line.
  • Top products: add up revenue per product over good rows, round each total to 2 decimals, keep products whose total is at least the cut-off, and list them from most to least revenue (same revenue: product name A to Z). Number them from 1. If none reach the cut-off, print one line, (none).
  • Best day: add up your chosen money (revenue or profit) per date over good rows, rounded to 2 decimals. If two days tie, the earlier date wins.
  • Weekday summary: one line per weekday that has at least one good row, from Monday to Sunday. Use full English day names.
  • First 3 orders: print str(order) for the first three good orders in the order of clean_orders.csv (fewer if there are fewer).
  • All money is printed with 2 decimals and a $.

The files your program writes

clean_orders.csv: built from a pandas DataFrame of the good rows. Exactly these six columns, in this order: order_id,date,product,quantity,revenue,profit. No index column. Revenue and profit have exactly 2 decimals (float_format="%.2f"). product is the final name after your rules. Sort the rows by date, then by order_id.

revenue_by_product.png: a bar chart of revenue per product (all good rows, every product) with a title and a y label. Put matplotlib.use("Agg") before import matplotlib.pyplot. Do not call plt.show(). The marking program checks that the file is a real picture. Your teacher looks at it.

Use groupby for the top products, the best day and the weekday summary.

USERNAME = ""  # you may type your GitHub username here, or leave it empty and type it when asked

v = pick("a3", username)
MAXQ, START, END = int(v["max_qty"]), v["start_date"], v["end_date"]
TIDY, COOKIE, METRIC = v["name_rule"] == "tidy", v["cookie_rule"], v["best_metric"]
print(f"Your rules: max quantity {MAXQ}, names {v['name_rule']}, Cookie {COOKIE}, best day by {METRIC}, "
      f"cut-off ${float(v['min_revenue']):.2f}, window {START} to {END}\n")

here = Path.cwd()
script = here / "messy_orders.py"
results = []


def check(label, test):
    try:
        outcome = test()
        ok, extra = (outcome if isinstance(outcome, tuple) else (bool(outcome), ""))
    except Exception as e:  # noqa: BLE001
        ok, extra = False, f"error: {type(e).__name__}: {e}"
    results.append(ok)
    print(("PASS  " if ok else "FAIL  ") + label + (f"   ({extra})" if extra and not ok else ""))


if not script.is_file():
    sys.exit("Could not find messy_orders.py in this folder. Open the assignment-3 folder in VS Code and run again.")
src = script.read_text(encoding="utf-8")
try:
    tree = ast.parse(src)
except SyntaxError as e:
    sys.exit(f"messy_orders.py has a syntax error: {e}")

# ---- a tiny data set. Dates move with YOUR window. Every row tests one rule.
S = datetime.date.fromisoformat(START)
E = datetime.date.fromisoformat(END)
d = lambda n: (S + datetime.timedelta(days=n)).isoformat()  # noqa: E731
rows = [  # id, date, product, quantity, what we expect
    ("M01", d(0), "Coffee", "1", "good"),
    ("M02", d(1), "Tea", str(MAXQ), "good"),
    ("M03", d(1), "Muffin", str(MAXQ + 1), f"quantity over {MAXQ}"),
    ("M04", d(2), "Muffin", "two", "quantity not a number"),
    ("M05", d(2), "Tea", "0", "quantity 0 or less"),
    ("M06", d(3), "Waffle", "1", "unknown product"),
    ("M07", (S - datetime.timedelta(days=1)).isoformat(), "Coffee", "1", "outside"),
    ("M08", (E + datetime.timedelta(days=1)).isoformat(), "Tea", "1", "outside"),
    ("M09", E.isoformat(), "Muffin", "2", "good"),
    ("M10", d(3), "Cookie", "1", "good-alias" if COOKIE != "bad" else "unknown product"),
    ("M11", d(4), "  coffee ", "1", "good" if TIDY else "unknown product"),
    ("M01", d(4), "Coffee", "2", "duplicate order id"),
    ("M13", "2026-13-45", "Tea", "1", "bad date"),
]
MENU = {"Coffee": ("4.00", "1.00"), "Tea": ("2.00", "0.50"), "Muffin": ("3.00", "1.20")}
good, counts, outside, aliased = [], {}, 0, 0
for oid, day, prod, qty, what in rows:
    if what == "outside":
        outside += 1
    elif what.startswith("good"):
        name = {"good-alias": COOKIE}.get(what, prod.strip().title())
        good.append((oid, day, name, int(qty)))
        aliased += what == "good-alias"
    else:
        counts[what] = counts.get(what, 0) + 1
good.sort(key=lambda g: (g[1], g[0]))


def money(x):
    return f"{Decimal(x).quantize(Decimal('0.01')):.2f}"


def totals(name_qty):
    _, _, name, qty = name_qty
    price, cost = (Decimal(x) for x in MENU[name])
    return price * qty, (price - cost) * qty


per_day = {}
for g in good:
    rev, prof = totals(g)
    per_day[g[1]] = per_day.get(g[1], Decimal(0)) + (rev if METRIC == "revenue" else prof)
best_day = max(sorted(per_day), key=lambda k: per_day[k])
bad_total = sum(counts.values())
labels = [("bad date", "bad date"), ("unknown product", "unknown product"), ("quantity not a number", "quantity not a number"),
          ("quantity 0 or less", "quantity 0 or less"), (f"quantity over {MAXQ}", f"quantity over {MAXQ}"),
          ("duplicate order id", "duplicate order id")]

work = Path(tempfile.mkdtemp(prefix="a3check_"))
shutil.copy(script, work / "messy_orders.py")
with open(work / "orders.csv", "w", newline="", encoding="utf-8") as f:
    w = csv.writer(f)
    w.writerow(["order_id", "date", "product", "quantity", "channel"])
    for oid, day, prod, qty, _ in rows:
        w.writerow([oid, day, prod, qty, "pickup"])
with open(work / "menu.csv", "w", newline="", encoding="utf-8") as f:
    w = csv.writer(f)
    w.writerow(["product", "price", "cost"])
    for name, (price, cost) in MENU.items():
        w.writerow([name, price, cost])


def run(folder, code_args=("messy_orders.py",), timeout=30):
    env = dict(os.environ, MPLBACKEND="Agg")
    return subprocess.run([sys.executable, *code_args], cwd=folder, capture_output=True, text=True, timeout=timeout, env=env)


try:
    p = run(work)
except subprocess.TimeoutExpired:
    sys.exit("Your program did not finish in 30 seconds. Is there a loop that never ends?")
lines = [l.strip() for l in p.stdout.splitlines()]


def line_is(expected):
    prefix = expected.split(":")[0] + ":"
    got = next((l for l in lines if l.startswith(prefix)), "no such line")
    return expected in lines, f"expected '{expected}', your program printed '{got}'"


check("program runs on the small test files without an error",

def csv_file():

        table = list(csv.reader(f))

def class_tests():
    cls = next((n for n in ast.walk(tree) if isinstance(n, ast.ClassDef) and n.name == "Order"), None)
    if cls is None:
        return False, "no class called Order"
    code = ("import json\n" + ast.get_source_segment(src, cls) + "\n"
            "a = Order('O1', '2026-03-01', 'Coffee', 3, 4.5, 1.5)\n"
            "b = Order('O1', '2030-05-05', 'Tea', 1, 3.0, 0.5)\n"
            "c = Order('O2', '2026-03-01', 'Coffee', 3, 4.5, 1.5)\n"
            "print(json.dumps([str(a), a.revenue(), a.profit(), a == b, a == c, a == 'O1']))\n")
    q = run(work, ("-c", code), 10)
    if q.returncode != 0:
        return False, (q.stderr.strip().splitlines() or ["error"])[-1]
    text, rev, prof, same_id, other_id, other_type = json.loads(q.stdout.strip().splitlines()[-1])
    return {"text": text, "rev": rev, "prof": prof, "same": same_id, "other": other_id, "type": other_type}, ""


holder = {}


def order_str():

    if not isinstance(out, dict):
        return False, note
    holder.update(out)
    want = "O1 | 2026-03-01 | Coffee x3 | revenue $13.50 | profit $9.00"
    return out["text"] == want and out["rev"] == 13.5 and out["prof"] == 9.0, f"str(order) gave '{out['text']}'"
