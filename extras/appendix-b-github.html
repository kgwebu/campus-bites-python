Appendix B. GitHub basics

I use a

GitHub is a website that stores your code. A repository (or "repo") is one project folder on GitHub. You will hand in your assignments by putting them in a repo. It takes about 30 minutes. Do Appendix A first. Pick your computer above and tick each step when done.

Your teacher's GitHub username is kgwebu. You will need it in Part 5. If your teacher gives you a different one in class, use that one.

Part 1. Make your GitHub account

Go to github.com. Click Sign up. Use an email you check often.

Choose a username that is simple and professional (for example sam-lee-codes). Do not use jokes or your birth year. Finish the steps, then open the email GitHub sends you and click Verify.

You should see: the GitHub home page with your username at the top right.

If it did not work
  • No verification email: check the spam folder, then click Resend on the GitHub page.
  • Username is taken: add a short word or your city, for example sam-lee-toronto.
  • The puzzle will not load: refresh the page, or try another browser.

Part 2. Install Git

Git is the tool that sends your files to GitHub. Check first. You may already have it.

Open Terminal (Cmd + Space, type Terminal, Enter). Type this and press Enter:

git --version

If you see git version 2.x.x, skip to Part 3. If a pop-up asks to install command line developer tools, click Install, wait for it to finish (it can take 10 minutes), then type the command again.

You should see: git version 2.x.x.

If it did not work
  • The pop-up never appears: close Terminal, open it again and retry. If it still fails, go to git-scm.com/download/mac and follow the installer there.
  • It says xcode-select: error: restart your Mac and try once more.

Go to git-scm.com/download/win. The download should start by itself. If not, click Click here to download. Open the .exe file.

Click Next on every screen without changing anything. Click Install. Click Finish.

Close any open PowerShell or VS Code windows. Open a new PowerShell. Type this and press Enter:

git --version

You should see: git version 2.x.x.

If it did not work
  • "git is not recognized": close every PowerShell and VS Code window, and open them again. If it still fails, restart the computer.
  • The installer asks lots of questions: you can click Next on all of them. The default choices are fine.

Part 3. Tell Git who you are

In the terminal type these two lines, one at a time. Use your own name, and the same email as your GitHub account. Press Enter after each line.

git config --global user.name "Your Name"
git config --global user.email "you@example.com"

Nothing is printed. That is normal.

Check it worked:

git config --global --list

You should see: user.name=Your Name and user.email=you@example.com in the list.

If it did not work
  • A long list starts and you cannot type: press q to leave it.
  • You made a typo: just type the command again with the right text.

Part 4. Connect VS Code to GitHub

Open VS Code. Click the Accounts icon (a small person at the bottom of the left bar). Click Sign in with GitHub to use GitHub Pull Requests... or Sign in to Sync Settings. A browser tab opens.

In the browser click Authorize Visual-Studio-Code. When the browser asks to open VS Code, click Open.

You should see: your GitHub username when you click the Accounts icon.

If it did not work
  • The browser says "cannot open VS Code": click Open Visual Studio Code on the page, or copy the link into VS Code under Accounts.
  • Nothing happens when you click: close VS Code, open it again, and retry.
  • A school network blocks GitHub: try a phone hotspot. If that fails, use Part 6 instead and tell your teacher.

Part 5. Make a repo and put work in it

Go to github.com. Click the + at the top right, then New repository.

Fill in the form:

  • Repository name: python-course-yourname (use your own name)
  • Private: select Private
  • Tick Add a README file

Click Create repository.

Add your teacher so they can see your work. In the repo click Settings, then Collaborators (left side), then Add people. Type the teacher username kgwebu and click Add kgwebu to this repository. GitHub may ask for your password.

Click the green Code button and click the small copy icon next to the web address that ends in .git.

In VS Code press Cmd+Shift+P (Mac) or Ctrl+Shift+P (Windows). Type Git: Clone and press Enter. Choose Clone from URL. Paste the address and press Enter. Choose a folder (use Documents). Click Select as Repository Destination. When VS Code asks to open the cloned repository, click Open.

You should see: your repo name at the top of the left bar, with a file called README.md inside.

If it did not work
  • "Authentication failed": sign in again from the Accounts icon (Part 4), then retry.
  • You cannot find Git: Clone: check that you typed Git: Clone and not Git: Clone Recursive.
  • The folder already exists: choose a different folder, or delete the old one first.
  • The Collaborators page is missing: you are in the wrong repo, or on someone else's repo. Open your repo.

Copy your setup_check.py file from Appendix A into this new folder. In VS Code you can drag it into the left bar. Or open the file, choose File, then Save As..., and save it inside the repo folder.

You should see: setup_check.py listed in the left bar, with a green U next to it.

Part 6. Commit and push

A commit is a saved snapshot. A push sends your commits to GitHub.

Click the Source Control icon on the left (three circles joined by lines). Under Changes you should see setup_check.py.

Click the + next to setup_check.py. This is called staging. It moves the file to Staged Changes.

Click in the Message box. Type Add setup check. Click Commit. If VS Code asks whether to stage all changes, click Yes.

Click Sync Changes (or Publish Branch / Push). If asked, click OK.

You should see: the blue button disappears.

Open your repo page on github.com and refresh it.

You should see: setup_check.py in the file list, and Add setup check next to it.

If it did not work
  • "Please tell me who you are": you skipped Part 3. Do it now and commit again.
  • Push is rejected or asks for a password: sign in again from the Accounts icon.
  • The Commit button is grey: type a message first. Also make sure you staged the file.
  • You cannot see the file on GitHub: refresh the page. Make sure you pushed, not just committed.

📤 Hand this in

Hand in two things:

  1. The link to your repo, for example https://github.com/yourname/python-course-yourname
  2. A screenshot of your repo page on github.com. It must show README.md and setup_check.py, with your commit message, and the Collaborators list showing kgwebu.

Hand in one file without Git (web upload)

You can send a file to your repo using only the website. Your teacher may ask you to do this for your first assignment.

Open your repo on github.com. Click Add file, then Upload files.

Drag your .py file into the box. Type a short message such as Assignment 1. Click Commit changes.

You should see: your file in the repo list.

If it did not work
  • You cannot drag files: click choose your files and pick the file from your folder.
  • The file shows as "binary" or is empty: you uploaded the wrong file. Upload it again, and replace the old one.

Final check

Before you hand in, make sure every box above is ticked. Your repo must be Private, must have the files you committed, and must list kgwebu as a collaborator.
