📝 Assignments

Assignment 1. Lunch Rush Calculator

Skills: variables, input(), numbers, f-strings, if / elif / else, for and while loops. Time: about 2 hours.

The story

Noon at Campus Bites. Amina shouts, "Luis, price these lunch orders fast!" The queue changes every day. You will write a program that handles any number of customers, checks everything people type, and prints a day summary.

There is no starter file. You create lunch_rush.py yourself.

🔢 Your numbers

Every student gets different numbers, worked out from the GitHub username. Type yours to see them. Your program and your self-check use these.

Every student has different prices and rules. Type your GitHub username in the card above. The numbers below fill in for you. A classmate's program will not pass your checks, and yours will not pass theirs.

What your program must do

Your numbers:

  • A coffee costs $. A muffin costs $.
  • Discount 1: the subtotal is $ and the discount is %.
  • Discount 2: the subtotal is $ and the discount is %. Discount 2 wins when both apply.
  • Delivery costs $. It is free when the amount after the discount is $ or more. Pickup never pays a fee.
  • Loyalty reward: every th customer (customer , then twice that, and so on) gets $ off the total. The total never goes below $0.00.

Steps of the program:

  1. Ask How many customers today?. It must be a whole number of 1 or more. Ask again until it is.
  2. For each customer, ask Coffees:, then Muffins:, then Delivery (yes/no):.
  3. Coffees and muffins must be whole numbers, 0 or more. Reject words, decimals like 2.5, negatives and empty answers. Ask again.
  4. Delivery must be yes or no in any capitals (YES, No, yEs). Anything else: ask again.
  5. Work out the subtotal, the discount, the delivery fee and the loyalty reward. Print the receipt.
  6. After all customers, print the day summary.

If two customers have the same biggest receipt, the first one is the biggest.

Check text with .isdigit(). It is True only when the text is made of digits. So "3".isdigit() is True, but "-3", "2.5", "abc" and "" are False. Use .lower() for the capitals. A while loop that asks again is how you "ask until it is valid".

What the output looks like

Each customer prints this. Replace each {...} with the real value. Money has a $ and two decimals.

Customer {number}
Subtotal: ${subtotal}
Discount: {percent}%
After discount: ${after_discount}
Delivery fee: ${fee}
Loyalty: -${loyalty_amount}
Total: ${total}

The Loyalty line is always printed. It shows -$0.00 for customers who get no reward. If the reward is bigger than the amount, show only what was really taken off, so the total is $0.00.

At the end:

Customers: {count}
Day total: ${day_total}
Average receipt: ${average}
Biggest receipt: ${biggest} (customer {number})

The words and symbols must match exactly. The prompts must be exactly How many customers today?, Coffees:, Muffins: and Delivery (yes/no):. Use f-strings such as f"{x:.2f}". Watch the edges: a subtotal exactly on a threshold, an after-discount amount exactly on the free-delivery limit, and a total that would go below zero.

Steps

Make a folder called assignment-1. Inside it, create a new empty file called lunch_rush.py. Do not look for a starter. Write the program from the spec above.

Build it in small pieces. First ask for the count and loop that many times. Then one customer with no checks. Then the discounts. Then delivery and loyalty. Then the summary. Then the checks on input. Run it after each piece.

Download variants.py and save it in the same folder. It works out your numbers.

"""Self-check for Assignment 1 (Lunch Rush Calculator).

Put this file, variants.py and your lunch_rush.py in the SAME folder, then run it.
It uses YOUR personal numbers (worked out from your GitHub username).
It tests some things. Your teacher's hidden checks test more, including edge cases.
"""
import re
import subprocess
import sys

from variants import pick

USERNAME = ""  # you may type your GitHub username here so it does not ask every time

# (coffees, muffins, delivery) for the main run: six customers
MAIN = [(2, 1, "yes"), (6, 3, "no"), (5, 5, "yes"), (12, 6, "yes"), (1, 0, "no"), (9, 9, "yes")]

FIELDS = {
    "subtotal": r"Subtotal: \$(\d+\.\d\d)(?!\d)",
    "rate": r"Discount: (\d+)%",
    "after": r"After discount: \$(\d+\.\d\d)(?!\d)",
    "fee": r"Delivery fee: \$(\d+\.\d\d)(?!\d)",
    "loyalty": r"Loyalty: -\$(\d+\.\d\d)(?!\d)",
    "total": r"Total: \$(-?\d+\.\d\d)(?!\d)",
}


def run(lines):
    """Run lunch_rush.py with these typed lines. Returns (output, problem)."""
    try:
        p = subprocess.run([sys.executable, "lunch_rush.py"], input="\n".join(lines) + "\n",
                           capture_output=True, text=True, timeout=10)
    except subprocess.TimeoutExpired:
        return "", "it did not finish in 10 seconds (a loop that never ends?)"
    if p.returncode != 0:
        last = (p.stderr.strip().splitlines() or ["(no message)"])[-1]
        return p.stdout, "it stopped with an error: " + last[:100]
    return p.stdout, ""


def lines_for(count, customers):
    out = [str(count)]
    for c, m, d in customers:
        out += [str(c), str(m), d]
    return out


def receipts(out):
    parts = re.split(r"Customer (\d+)(?!\d)", out)
    found = {}
    for i in range(1, len(parts) - 1, 2):
        found.setdefault(int(parts[i]), {k: (re.search(rx, parts[i + 1]) or [None, None])[1] for k, rx in FIELDS.items()})
    return found


def summary(out):
    def last(rx):
        hits = re.findall(rx, out)
        return hits[-1] if hits else None
    return {"n": last(r"Customers: (\d+)"), "day": last(r"Day total: \$(\d+\.\d\d)(?!\d)"),
            "avg": last(r"Average receipt: \$(\d+\.\d\d)(?!\d)"),
            "big": last(r"Biggest receipt: \$(\d+\.\d\d) \(customer (\d+)\)")}


def main():
    name = USERNAME.strip() or input("GitHub username: ").strip()
    v = pick("a1", name)
    cp, mp = float(v["coffee_price"]), float(v["muffin_price"])
    t1, r1, t2, r2 = float(v["disc1_over"]), int(v["disc1_rate"]), float(v["disc2_over"]), int(v["disc2_rate"])
    at_least = v["compare"] == "at least"
    fee_amount, free_from = float(v["delivery_fee"]), float(v["free_from"])
    k, off = int(v["loyalty_every"]), float(v["loyalty_off"])

    def rate_for(sub):
        def over(t):
            return sub >= t - 1e-9 if at_least else sub > t + 1e-9
        return r2 if over(t2) else r1 if over(t1) else 0

    out, problem = run(lines_for(len(MAIN), MAIN))
    got = receipts(out)
    sm = summary(out)
    fails = []

    def check(label, ok, detail=""):
        if not ok:
            fails.append((label, detail))
        return ok

    def each(label, test):
        """test(i, customer_input, printed) returns '' when fine, or a short complaint."""
        if problem:
            return check(label, False, problem)
        for i, cust in enumerate(MAIN, 1):
            row = got.get(i)
            if row is None or any(x is None for x in row.values()):
                return check(label, False, f"customer {i}: a receipt line is missing or not in the exact format")
            msg = test(i, cust, {a: float(b) for a, b in row.items()})
            if msg:
                return check(label, False, f"customer {i}: {msg}")
        return check(label, True)

    total_checks = 12
    check("The program runs and finishes", not problem, problem)
    check("Every receipt has all 7 lines in the right format",
          not problem and len(got) == len(MAIN) and all(all(x is not None for x in r.values()) for r in got.values()),
          problem or "a line is missing, reworded or has the wrong number of decimals")
    each("Subtotal uses your prices", lambda i, c, r: "" if abs(r["subtotal"] - (c[0] * cp + c[1] * mp)) < 0.005
         else f"Subtotal should be {c[0] * cp + c[1] * mp:.2f}")
    each("Discount percent follows your two thresholds", lambda i, c, r: "" if int(r["rate"]) == rate_for(c[0] * cp + c[1] * mp)
         else f"Discount should be {rate_for(c[0] * cp + c[1] * mp)}%")
    each("After discount matches subtotal and percent", lambda i, c, r: "" if abs(r["after"] - r["subtotal"] * (100 - r["rate"]) / 100) < 0.006
         else "After discount does not match Subtotal and Discount")

    def fee_test(i, c, r):
        want = fee_amount if (c[2] == "yes" and r["after"] < free_from - 1e-9) else 0.0
        return "" if abs(r["fee"] - want) < 0.005 else f"Delivery fee should be {want:.2f}"
    each("Delivery fee: pickup is free, delivery is free from your limit", fee_test)

    def loyalty_test(i, c, r):
        before = r["after"] + r["fee"]
        want = min(off, before) if i % k == 0 else 0.0
        return "" if abs(r["loyalty"] - want) < 0.006 else f"Loyalty should be -${want:.2f}"
    each("Loyalty amount only on every k-th customer", loyalty_test)
    each("Total = after discount + fee - loyalty, never below 0",
         lambda i, c, r: "" if abs(r["total"] - (r["after"] + r["fee"] - r["loyalty"])) < 0.006 and r["total"] >= 0
         else "Total does not match the lines above it")

    ok = not problem and all(x is not None for x in sm.values()) and len(got) == len(MAIN)
    if ok:
        totals = [float(got[i]["total"]) for i in range(1, len(MAIN) + 1)]
        best = max(totals)
        first = totals.index(best) + 1
        ok = (sm["n"] == str(len(MAIN)) and abs(float(sm["day"]) - sum(totals)) < 0.006
              and abs(float(sm["avg"]) - sum(totals) / len(totals)) < 0.0051
              and abs(float(sm["big"][0]) - best) < 0.006 and sm["big"][1] == str(first))
    check("Day summary: count, total, average, biggest receipt and who", ok,
          problem or "one of the four summary lines is missing or wrong")

    two = [(3, 2, "yes"), (4, 1, "no")]
    out2, prob2 = run(["abc", "0", "-3", "2.5"] + lines_for(2, two))
    check("Asks again for a bad customer count", not prob2 and summary(out2)["n"] == "2",
          prob2 or "after bad answers it should ask again, then use 2")
    bad = ["2", "-1", "x", "3", "2.5", "1", "maybe", "y", "yes", "0", "0", "no"]
    out3, prob3 = run(bad)
    r3 = receipts(out3)
    ok3 = (not prob3 and len(r3) == 2 and r3.get(1, {}).get("subtotal") == f"{3 * cp + 1 * mp:.2f}"
           and r3.get(2, {}).get("subtotal") == "0.00")
    check("Asks again for bad coffees, muffins and delivery answers", ok3,
          prob3 or "bad answers should be rejected and asked again, not used")

    passed = total_checks - len(fails)
    for label, detail in fails:
        print(f"FAIL  {label}   ({detail})")
    print(f"\n{passed} of {total_checks} checks passed.")
    if fails:
        print("Tip: the hidden checks also test exact threshold amounts and strange input.")


if __name__ == "__main__":
    main()

Run the self-check until it says 12 of 12 checks passed. Then test the edges by hand. Your teacher's hidden checks use other customers, bad input, and amounts exactly on your thresholds.

Create NOTES.md in the same folder. Write one bug you hit and how you fixed it (3 to 5 sentences).

If it did not work
  • FAIL but your numbers look right: compare the text letter by letter. Look for a missing $, a missing space, or 26.1 instead of 26.10.
  • "it stopped with an error": read the last line of the message. It names the line and the problem (see Class 1, Reading errors).
  • ValueError on int(...): you converted before you checked. Check with .isdigit() first, then convert.
  • The discount is wrong at exactly the threshold: read your rule again. It says "over" or "at least". These are > and >=.
  • The self-check cannot find lunch_rush.py: it must be in the same folder and have exactly that name.
  • No module named variants: save variants.py in the same folder as the self-check.

Keep it honest

  • Write the code yourself. Talking about ideas is fine. Copying a file is not.
  • Your numbers are different from your classmates', so copied code gives wrong answers.
  • Your teacher may ask you to explain any part of your code in a 2-minute live chat. An assignment you cannot explain will not get the "Correct results" marks.
  • Include NOTES.md with one bug you hit and how you fixed it.
