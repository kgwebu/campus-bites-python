Appendix A. Run Python in VS Code

I use a

Until now you wrote code in the browser. Now you will run Python on your own computer, the way programmers do. It takes about 30 minutes. Pick your computer above. Do one step at a time and tick it when done.

Stuck? Open If it did not work under the step. Still stuck? Tell your teacher which step number and what you see on screen.

Part 1. Install Python

Open Safari or Chrome. Go to python.org/downloads. Click the big yellow Download Python 3.x button. You will get a file ending in .pkg.

Open the downloaded .pkg file. Click Continue on each screen, then Agree, then Install. Type your Mac password if asked. Click Close when it says the installation was successful.

Open Terminal. Press Cmd + Space, type Terminal, press Enter. Type this and press Enter:

python3 --version

You should see: Python 3.11.x or higher (for example Python 3.13.1).

If it did not work
  • command not found: python3: the install did not finish. Open the .pkg again and finish every screen. Then close Terminal and open a new one.
  • A pop-up asks to install "command line developer tools": click Install, wait until it ends, then type the command again.
  • You see Python 3.9 or lower: download the newest installer from python.org and run it again.
  • Your Mac says the file is from an unidentified developer: right-click the file, choose Open, then Open again.

Open Edge or Chrome. Go to python.org/downloads. Click the big yellow Download Python 3.x button. You will get a file ending in .exe.

Open the downloaded .exe file. Before you click anything else, tick the box at the bottom that says Add python.exe to PATH. Then click Install Now. Click Yes if Windows asks permission. Click Close when it says the setup was successful.

Do not skip the Add python.exe to PATH box. Most Windows problems come from missing it.

Open PowerShell. Click the Start button, type PowerShell, press Enter. Type this and press Enter:

python --version

You should see: Python 3.11.x or higher (for example Python 3.13.1).

If it did not work
  • "Python was not found; run without arguments to install from the Microsoft Store": Windows is using a fake shortcut. Press the Start button, type Manage app execution aliases, open it, and turn OFF both python.exe and python3.exe entries called App Installer. Open a new PowerShell and try again.
  • "python is not recognized": you missed the PATH box. Run the installer again, choose Modify, then Next, tick Add Python to environment variables, click Install. Open a new PowerShell and try again.
  • It works only in a new window: that is normal. Always open a new PowerShell after installing.
  • Still failing? Uninstall Python (Settings, Apps), restart the computer, and install again, this time ticking the PATH box.

Part 2. Install VS Code

Go to code.visualstudio.com. Click the big blue Download button. It picks the right version for your computer.

Open the downloaded zip. Drag Visual Studio Code into your Applications folder. Open it from Applications. Click Open if your Mac asks.

Open the downloaded installer. Choose I accept the agreement, then click Next until you reach the Select Additional Tasks screen. Tick Add to PATH and Add "Open with Code" action to Windows Explorer file context menu, then click Next and Install. Click Finish.

VS Code opens with a Welcome page. Close the welcome tab if you like.

You should see: a dark window with a sidebar on the left.

If it did not work
  • You cannot install programs (a school or work laptop): tell your teacher now. See "No admin rights?" at the bottom of this page.
  • The download is very slow: wait. If it stops, try again on a different network.

Part 3. Add the Python extension

In VS Code click the Extensions icon on the left (four small squares). Or press Cmd+Shift+X (Mac) or Ctrl+Shift+X (Windows).

In the search box type Python. Find the one called Python published by Microsoft (it has millions of downloads). Click Install.

You should see: the button changes to Disable or Uninstall.

If it did not work
  • Many results appear: pick the one that says Microsoft under the name.
  • Install button does nothing: close VS Code, open it again, and retry. Check your internet.

Part 4. Make your project folder

Open Finder. In Documents, make a new folder called python-course (Cmd+Shift+N).

Open File Explorer. In Documents, right-click, choose New, then Folder, and name it python-course.

In VS Code choose File, then Open Folder.... Select the python-course folder and click Open (Mac) or Select Folder (Windows). If VS Code asks Do you trust the authors? click Yes, I trust the authors.

You should see: PYTHON-COURSE at the top of the left sidebar.

In the sidebar, hover over the folder name and click the New File icon. Name the file hello.py and press Enter.

Click into the empty file and type exactly this, with your own name:

name = "Your Name"
print("Hello from", name)

Save with Cmd+S (Mac) or Ctrl+S (Windows).

Part 5. Run it

Click the Run button (a small triangle) at the top right of the editor.

You should see: a panel opens at the bottom, and it shows Hello from Your Name with your name.

Now run the same file from the terminal. In VS Code choose Terminal, then New Terminal. Type the command for your computer and press Enter.

python3 hello.py

python hello.py

You should see: the same message again.

If it did not work
  • VS Code asks to select an interpreter: click the message, then pick the newest Python from the list (the one that says 3.11 or higher).
  • python3: can't open file: the terminal is in the wrong folder. Type cd ~/Documents/python-course and try again.
  • No triangle button: the file does not end in .py, or the Python extension is not installed. Check Part 3.
If it did not work
  • VS Code asks to select an interpreter: click the message, then pick the newest Python from the list (the one that says 3.11 or higher).
  • "running scripts is disabled on this system" (red text): in the terminal type Set-ExecutionPolicy -Scope CurrentUser RemoteSigned and press Enter. Type Y if asked. Close the terminal and open a new one.
  • "can't open file": the terminal is in the wrong folder. Type cd ~\Documents\python-course and try again.
  • No triangle button: the file does not end in .py, or the Python extension is not installed. Check Part 3.

Part 6. Do the setup check

Download this file, or copy and paste it into a new file called setup_check.py in your python-course folder:

📄 setup_check.py
import platform
import sys

name = input("Type your full name: ")
print()
print("Name:", name)
print("Python:", sys.version.split()[0])
print("Computer:", platform.system(), platform.release())
if sys.version_info >= (3, 11):
    print("Result: READY")
else:
    print("Result: please install a newer Python")

Run it from the Run button. Click in the terminal at the bottom when it asks for your name, type your name and press Enter.

You should see: your name, your Python version, your computer, and Result: READY.

If it did not work
  • Result: please install a newer Python: go back to Part 1 and install the newest version. Then pick it in VS Code: press Cmd+Shift+P (Mac) or Ctrl+Shift+P (Windows), type Python: Select Interpreter, and pick the newest one.
  • It asks for your name but nothing happens when you type: click inside the terminal panel first.

📤 Hand this in

Take one screenshot that shows both:

  • the setup_check.py file open in VS Code, and
  • the terminal output with your name, your Python version, and Result: READY.

Name the screenshot setup-yourname.png and hand it in the way your teacher says.

Screenshot keys: Mac Cmd+Shift+4, then drag. Windows Windows+Shift+S, then drag.

No admin rights, or it still will not work?

If your laptop is locked and you cannot install anything, do not worry.

  • Tell your teacher. They will give you another way to hand in this task.
  • You can keep using the course website in your browser. Every lesson and practice task works there.
  • Your teacher may set you up with a browser-based editor. You will do the same task there and hand in the same kind of screenshot.

Final check

Before you hand in, make sure every box above is ticked, hello.py prints your name, and setup_check.py shows Result: READY.
