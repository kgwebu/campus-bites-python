Group project. Campus Bites Expands

Amina wants to grow Campus Bites. Each group gets one new business idea with its own menu, data and rules. Your group builds a Python program that reads the data, applies the business rules, finds answers, and makes a short report with charts. In Week 8 you present it to the class.

Skills: everything in the course. Input and decisions, loops, dictionaries, functions in several modules, files and bad data, a class, pandas and charts.

Your scenario

Your teacher gives each group a number from 1 to 7. Open your scenario page in the menu. It has your story, your data files, your two business rules, your class and your three questions.

What every group must build

# Requirement
1 Read your menu file and sales file (CSV)
2 Clean the data. Count good rows and bad rows with try / except
3 Turn both business rules into functions
4 At least 6 functions in at least 2 modules (separate .py files)
5 At least 1 class that holds data and has methods
6 Use pandas to answer your 3 questions
7 At least 2 charts saved as .png files, each with a title and labels
8 One command (python main.py) runs everything and writes report.txt
9 A README.md that explains the project and how to run it on Mac and Windows

Set up your team repo

Choose one person to create the group repo (see Appendix B). Name it python-course-group-N (N is your group number). Make it Private.

Add every teammate and kgwebu as collaborators.

Everyone clones the repo into VS Code. Every teammate must commit and push their own work. Your teacher reads the commit history.

Put your scenario files, your code and your README in the repo.

A good split: one person on data loading, one on rules, one on the class, one on analysis and charts. Everyone helps with the README and the slides. Swap code reviews: each person reads a teammate's function before it is merged.

Milestones

Milestone Due before What your repo must show
M1: Plan and data Class 6 Repo set up. README with your plan. Data loads. Good and bad row counts match your scenario page
M2: Rules and class Class 7 Both rules are functions. The class works. A few assert checks pass
M3: Findings Week 8 Three questions answered, two charts, report.txt, and slides drafted
Presentation Week 8 8 minutes of talk and demo, then 4 minutes of questions

Your teacher will look at your repo at each milestone and give short feedback.

Self-check

Download this file and run it in your project folder (the folder with main.py). It checks that your project has the right shape.

📄 gp_selfcheck.py
Show the code
"""Self-check for the group project. Put it in your project folder (next to main.py) and run it.

It checks the SHAPE of your project: files, functions, a class, error handling, a README, a report and charts.
It does not judge whether your analysis is right. Your teacher does that.
"""
import ast
import glob
import os
import subprocess
import sys

results = []


def check(label, test):
    try:
        ok = bool(test())
    except Exception as e:
        ok = False
        label += f"   (error: {type(e).__name__}: {e})"
    results.append(ok)
    print(("PASS  " if ok else "FAIL  ") + label)


mine = [p for p in glob.glob("*.py") if "selfcheck" not in p]
trees = {}
for p in mine:
    try:
        trees[p] = ast.parse(open(p, encoding="utf-8").read())
    except SyntaxError as e:
        print(f"FAIL  {p} has a syntax error on line {e.lineno}")
        results.append(False)

funcs = sum(isinstance(n, ast.FunctionDef) for t in trees.values() for n in ast.walk(t))
classes = sum(isinstance(n, ast.ClassDef) for t in trees.values() for n in ast.walk(t))
modules_with_funcs = [p for p, t in trees.items() if p != "main.py" and any(isinstance(n, ast.FunctionDef) for n in ast.walk(t))]
all_src = "\n".join(open(p, encoding="utf-8").read() for p in trees)

check("there is a main.py", lambda: os.path.exists("main.py"))
check("at least 2 modules besides main.py hold functions", lambda: len(modules_with_funcs) >= 2)
check("at least 6 functions in total", lambda: funcs >= 6)
check("at least 1 class", lambda: classes >= 1)
check("uses try/except for bad data", lambda: any(isinstance(n, ast.Try) for t in trees.values() for n in ast.walk(t)))
check("uses pandas", lambda: "import pandas" in all_src)
check("makes charts with matplotlib", lambda: "matplotlib" in all_src)
check("README.md has at least 80 words", lambda: len(open("README.md", encoding="utf-8").read().split()) >= 80)

for name in ("report.txt",):
    if os.path.exists(name):
        os.remove(name)
for png in glob.glob("*.png"):
    os.remove(png)

if os.path.exists("main.py"):
    run = subprocess.run([sys.executable, "main.py"], capture_output=True, text=True, timeout=120)
    if run.returncode != 0:
        print("\nmain.py stopped with an error:\n" + (run.stderr.strip()[-600:] or "(no message)"))
    check("main.py runs without an error", lambda: run.returncode == 0)
check("main.py wrote a report.txt that is not empty", lambda: os.path.getsize("report.txt") > 50)
check("main.py saved at least 2 chart pictures (.png)", lambda: len(glob.glob("*.png")) >= 2)
print(f"\n{sum(results)} of {len(results)} checks passed.")

Run it with python gp_selfcheck.py (Mac: python3 gp_selfcheck.py). Aim for 11 of 11.

If it did not work
  • "at least 2 modules besides main.py hold functions": split your code into files such as data_io.py, rules.py, analysis.py, and import them in main.py.
  • "main.py runs without an error": read the message printed above. The last line names the file, the line number and the problem.
  • "saved at least 2 chart pictures": use plt.savefig("name.png"). Do not use plt.show().
  • It cannot find your data files: they must be in the same folder as main.py, and VS Code must have that folder open.
